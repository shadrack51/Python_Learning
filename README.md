# Python Learning Dashboard

A simple Streamlit dashboard for uploading a CSV file, previewing data, and displaying average salaries by department.

## Setup

1. Create and activate a Python virtual environment:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

2. Install dependencies:

```powershell
pip install -r requirements.txt
```

3. Run the app:

```powershell
streamlit run app.py
```
